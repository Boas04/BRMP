Catatan pengelolaan

Konten terbit menjadi sumber chatbot. Tulis fakta lengkap, tanggal berlaku, dan tautan rujukan. Jangan memasukkan kredensial atau data pribadi. Perubahan berlaku setelah halaman publik dimuat ulang. Konten yang diimpor selalu masuk sebagai draf. Foto menggunakan file di direktori public/assets.

Impor konten JSON

Format: objek dengan properti records, seperti hasil ekspor. Maksimal 100 record / 128 KB. Konten diimpor sebagai draf baru; pengaturan situs dilewati; periksa agar tidak menduplikasi konten.
